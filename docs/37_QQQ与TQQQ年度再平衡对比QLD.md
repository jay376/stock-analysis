# QQQ与TQQQ年度再平衡，对比QLD

数据截至2026-10-30。每年首个共同交易日收盘先投入10,000美元，再将整个账户的QQQ和TQQQ调整到各50%，包括卖出超配资产；不是仅把新钱各投一半。其余交易日不再平衡。不再平衡对照则每年新钱各半、原持仓不调整；两种投入方式已合并在本篇。全部使用实际ETF复权价格，包含分配再投资，允许小数份额，未扣个人税、交易佣金、点差和滑点。与旧研究采用相同交易日和投入金额。

## 回撤与验证

最大回撤在CSV中使用贡献调整后的单位净值，移除新增资金机械抬高账户资产的影响。再平衡日之后目标日敞口为2倍，但其余时间权重仍会变化，并不等同于QLD的每日2倍目标。

独立核验采用40位Decimal按每两个再平衡日之间的QQQ、TQQQ实际复权价格比计算年度账户递推，与逐日持仓估值比较；所有23个窗口通过。检验每次再平衡后的持仓各半、交易前后资金守恒，以及XIRR净现值残差。年度交易明细见annual_rebalance_trades.csv。

本篇保留年度定投至今及五年对照；普通组合的完整10年结果统一见[10年普通定投汇总](25_普通TQQQ年度定投30组结果.md)。
