# 普通年度定投：30组滚动10年完整结果

每年1月首个交易日收盘投入10,000美元，无额外初始本金，全仓持有各自基金。数据截至2026-10-30。1995—2005表示1995年初投入到2005年初之前，期末为2004年最后交易日；完整窗口10笔、本金100,000美元。1995—2016起点的22组完整，2017—2024起点的8组未完成，不能当作完整10年收益。

XIRR是实际入金日期对应的年化收益；最大回撤按剔除入金影响的投资净值计算。峰值按每日收盘、当日入金后的账户资产记录；峰值利润扣除当天累计本金，峰值收益率也使用当天本金，未假设在峰值卖出。下表金额单位均为**万美元**。

## 数据、模型与检验

实际ETF调整收盘价已计入分配再投资及基金内部费用。TQQQ自2010-02-11起、QLD自2006-06-21起使用实际行情；此前分别模拟每日3倍、2倍收益，扣2倍、1倍前一已知IRX国债利率作为融资成本及假设1%年费，按日历天数摊销。QQQ成立前使用NDX价格收益，缺少该阶段指数股息；QQQ有行情后使用调整收盘价。成立前结果属于模拟，不能视为真实基金历史。

保留原研究截止日期与计算结果。本次按年度投入批次独立重建60组每日账户，核对期末资产、本金及现金流XIRR，并据此补齐每日资产峰值。允许碎股，未计个人税费、佣金、点差和滑点。重叠窗口并非独立样本。
