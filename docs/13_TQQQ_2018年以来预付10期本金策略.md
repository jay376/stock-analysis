# TQQQ 回撤80%后预付10期本金策略

**本策略替代此前额外增加本金的十倍定投：集中投入的是未来月供，后续相应暂停。本金最终仍为107,000美元。**

## 执行规则

- 回测2018-01-01至2026-10-30；实际首笔2018-01-02。初始1,000美元加首月1,000美元，之后每月预算1,000美元，合计106期月供及107,000美元本金。
- TQQQ每日拆股调整收盘价从截至当日的上市以来最高收盘价回撤达到80%时，下一期月度买入日集中投入10个月预算，共10,000美元。分红不调整触发价格，分红再投资用于账户估值。
- 10期包含执行当月及其后9个月，执行后第10个月恢复普通月供；后续提前投入的批次接在已有预付月份之后。
- 每次集中投入6个月后按当月首个交易日复查，以前一个交易日收盘回撤判断；若仍达到80%，再投入10个尚未覆盖的月份。已有预付月份不重复扣本金，恢复月供时间累计顺延。
- 预付暂停期间不因80%线附近反复波动再次立即投入，只执行半年复查；复查不满足条件则不投入新批次，待剩余预付月份消耗完恢复普通月供。
- 主结果按回撤恢复到80%以内、之后再次跌破视为新一轮；“必须收复原高点才开启新一轮”的结果另外列出。
- 不预付2026年10月以后的预算，所以各策略期末总本金均为107,000美元。资金投入时间提前，需要在集中买入时已备好相应资金；不计现金等待收益或资金借用成本。

## 数据与验证

使用[Yahoo TQQQ历史行情](https://finance.yahoo.com/quote/TQQQ/history/)的完整历史复权价格序列。实际ETF价格已包含基金运作成本，股息再投资以复权总回报近似，允许碎股。未计个人税费、佣金和滑点。

每日核对本金等于已到期月份预算加剩余预付月份预算；106个月份各覆盖且只覆盖一次；各策略总本金107,000美元、期末预付余额为0；期末资产经独立逐笔估值核对；XIRR现金流净现值残差小于0.000001美元。触发不使用未来高点或未来价格；半年复查使用前一交易日收盘。
