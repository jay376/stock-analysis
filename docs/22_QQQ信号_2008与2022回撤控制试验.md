# 如何降低2008与2022式回撤：QQQ信号与杠杆ETF策略试验

先固定比较7种策略，再针对全仓回撤仍偏大的结果增加200日均线配合目标半仓，共8种。没有扫描参数后挑选历史最优。沿用初始1,000美元、每月首个交易日1,000美元；空仓月份资金积存在现金，买回时投入。

## 数据与执行

- 2008年没有TQQQ实盘行情，用实际每日2倍QLD，2006-06-21至2010-12-31，55期月供、56,000美元总本金。2022年用实际每日3倍TQQQ，2018-01-02至2026-10-30，106期月供、107,000美元总本金。两种杠杆的结果不能直接当作同一种产品比较。
- 所有信号看QQQ拆股调整收盘价；周线为周五结束的已完成交易周，节假日取该周最后交易日。均线包含确认日收盘，周均线按周收盘计算，日均线按交易日收盘计算；使用2005年起历史预热。
- 信号次一交易日开盘执行。起始仓位使用起始日前已知信号；每月第一交易日收盘继续入金并平衡到当前目标仓位，0/100%策略相当于存现金或买入。50%仓位在每个周线执行日和月供日平衡，其余时间会随股价漂移；200日半仓方案仍按每日均线信号退出/买回，半仓的周度平衡不改变日线信号。
- 账户用实际ETF分红复权总回报近似；允许碎股。现金利息按0，未计个人税费、佣金、滑点。清仓后现金持续留在账户，XIRR仅使用外部入金和期末价值。
- 回撤使用剔除入金影响的投资净值；危机回撤包含危机前高点：2007—2009年、2021—2022年。它不是从股价高点回撤，而是对应策略的投资净值回撤。

## 固定规则

| 策略 | 退出/降仓 | 买回/增仓 |
|---|---|---|
| 普通定投 | 一直100%持仓 | 每月买入 |
| 现有20周前价格法 | 连续两周各自低于20周前收盘，0% | 连续两周各自高于20周前收盘，100% |
| 20周均线 | 一周收盘低于20周均线，0% | 一周收盘高于均线，100% |
| 10周均线 | 一周收盘低于10周均线，0% | 一周收盘高于均线，100% |
| 200日均线缓冲 | 日收盘低于200日均线×0.99，0% | 日收盘高于200日均线×1.01，100%；中间保持原状态 |
| 分档降仓 | 同时高于10/20周均线100%；只高于其中一条50%；都不高于0% | 每周按同一条件增减仓位 |
| 10周均线+半仓 | 一周收盘不高于10周均线，0% | 高于10周均线时目标50%；其余为现金 |
| 200日均线+半仓 | 日收盘低于200日均线×0.99，0% | 日收盘高于200日均线×1.01，目标50%；中间保持状态 |

## 候选方案与取舍

若优先减轻危机级回撤，200日均线加1%缓冲、目标50%TQQQ仓位是本组回测中的候选：2007—2009年QLD策略净值最大回撤25.12%，2021—2022年TQQQ最大回撤16.10%；TQQQ全区间最大回撤仍为33.10%，发生在2020年。2018至今107,000美元本金的期末资产305,671美元，XIRR约22.59%。
规则：QQQ日收盘低于200日均线的99%时，次一交易日开盘清仓；高于101%时买回到目标50%TQQQ、50%现金；处于缓冲带维持原状态。日线信号决定进出，持有半仓时每周和月供日平衡仓位。空仓期间月供继续存现金。
全仓200日均线方案在2018至今的期末资产更高（720,765美元），但全区间最大回撤58.56%，2020年快速下跌仍造成重损。若只查看2008和2022而忽略2020，会高估它的风险控制能力。目标半仓的收益较低，这是实际取舍。

## 如何解读

20周前价格比较的基准会随历史价格移动，连续两周确认又增加延迟；它可能在快速崩跌后才退出。更短均线缩短延迟，但也可能反复清仓，并在更高价格买回。半仓降低市场暴露，同时减少上涨期收益。
这些是同一组有限历史样本的事后试验，不能证明未来会避免大跌。周末确认只能在下一交易日执行，跳空下跌仍会直接影响退出价格。单一信号无法承诺最大亏损上限；降低杠杆和股票仓位比单独改变止损线更直接地减少风险。
2008与2022是已知危机，不应把它们当作独立样本外证明。2023—2026结果用于展示回升与震荡期间的代价，同样属于历史回测。

## 验证

每个窗口所有策略外部入金日期和金额完全相同；普通定投以独立逐笔持仓估值核对；每种策略以独立买卖批次重放核对每一天的股票和现金总额；所有信号执行日晚于确认日；XIRR净现值残差小于0.000001美元。
