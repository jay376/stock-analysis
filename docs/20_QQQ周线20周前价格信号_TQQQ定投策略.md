# QQQ周线20周前价格信号：TQQQ定投与清仓策略

**信号看QQQ，实际买卖TQQQ；买卖都比较20周前的周收盘价，不使用20周均线。**

## 执行规则

- 回测2018-01-02至2022-12-30（2018年开始持续5年）。初始投入1,000美元，加每月首个交易日1,000美元，首笔共2,000美元，60期月供，总本金61,000美元。
- 初始持有TQQQ。QQQ连续两个已结束交易周的周收盘价，各自低于20个交易周前的周收盘价，清仓全部TQQQ；连续两周各自高于对应20周前价格，买回全部可用现金。等于时不满足条件。
- 每周以周五为结束日期；节假日缩短周取该周最后交易日收盘。使用2017年QQQ数据预热20周比较，允许2018年首周引用2017年末的一周确认，但2018年前不执行交易。
- 周末确认信号，下一个交易日按TQQQ开盘价执行。持仓时忽略重复买入信号，空仓时忽略重复卖出信号。
- 每月定投不预付、不中断：持仓时当月资金在首个交易日收盘买入TQQQ；空仓时存入现金。买回按开盘价投入已有全部现金；若当天恰逢月供，新增月供在收盘另行买入。
- QQQ信号使用拆股调整收盘价、不做分红调整。账户用TQQQ分红复权收盘价以及同日复权因子调整的开盘价计算，近似分红再投资，允许碎股；表中TQQQ股价还原为当时实际价格。
- 现金收益按0；基金费用已体现在行情，未计个人税费、佣金、滑点。账户总额包含股票和现金，空仓不代表停止投入。
