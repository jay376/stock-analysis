# TQQQ当年亏损90%当天预付3年：逐组与投入过程

每年1月首个交易日收盘投入10,000美元。年度价格收益率以去年最后一个交易日收盘价为基准，每年重置；首次严格低于−90%，当天收盘额外预付未来3个尚未覆盖的年度预算，最多30,000美元。即使前批尚未到期，下一年也允许重新触发；每年最多一批。已覆盖年度暂停普通投入，不预付估值截止后的预算。完整10年本金100,000美元。

## 总体结果

22组完整10年中，10组改善、4组变差、8组相同。新策略期末资产中位数736,344美元，XIRR中位数34.57%；最差期末资产15,901美元（1996开始），最差XIRR−27.69%（1995开始）。6组最终亏损；投资净值最差回撤仍−99.98%。

## 数据与限制

数据截至2026-10-30。TQQQ 2010-02-11成立之前的事件来自每日3倍模拟，所有90%触发均发生在模拟期；2022年实际当年最大价格亏损约80.57%，未触发。窗口相互重叠，不能当成独立试验。当天收盘信号与成交于同一收盘价为理想化假设，允许碎股，不计个人税费、交易费用和预备本金利息。XIRR为实际现金流年化，表格累计收益率为资产/已投本金−1，两者不同。
