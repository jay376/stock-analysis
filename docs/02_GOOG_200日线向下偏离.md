# GOOG相对200日均线的向下偏离

数据截至：2026-10-29。标的GOOG；上市历史从2004-08-19开始，满200个交易日后才计算均线，首个有效均线日期为2005-06-03。

## 计算口径

SMA200为当日及此前199个交易日收盘价的算术平均。偏离率＝（股价÷SMA200−1）×100%。采用Yahoo拆股调整日线，不含股息。2020年以来的研究仅限制观察日期，仍保留此前计算均线所需的交易日。

盘中最低价使用该日收盘时计算出的SMA200作为比较基准，不是实时盘中均线。
