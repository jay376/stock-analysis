# SOXL 回撤80%后下一期十倍定投回测

最新修订采用预付未来月份本金并暂停后续月供，见[11 预付10期本金策略](11_SOXL_回撤80后预付10期本金策略.md)。本文保留此前额外增加本金方案的结果。

**结果：回撤触发加仓共11次，总本金182,000美元，期末资产约920,670美元。**

## 策略口径

- 2020-01-01至2026-10-30；实际首笔2020-01-02。初始1,000美元，每月1,000美元，首月共2,000美元。每月首个交易日按收盘价买入。
- 标的为SOXL。使用每日拆股调整收盘价判断回撤，不使用账户余额；历史高点取上市以来截至当日已出现的最高收盘价。分红不调整触发价格，分红再投资用于资产估值。
- 当回撤首次从不足80%变成达到或超过80%时，触发下一期月供10,000美元，替代当期1,000美元，因此每次额外投入9,000美元。
- 执行后恢复普通月供。持续处于80%以上回撤区间不逐月重复加仓。恢复到回撤不足80%后，再次跌破才会重新触发；不要求先创新高。
- 同一买入日之前出现多次触发，只安排一次10,000美元；已触发的加仓不会因买入前反弹而取消。信号日当天收盘才知道信号，因此当天月供不受当天信号影响。
- 同本金均匀定投作为对照：初始1,000美元不变，每月约2,207.32美元，82笔月供，总本金同为182,000美元。该对照假设能按该月供持续投入，不是相同逐笔现金流。
