# GOOG偏离200日线后，多久收盘创新高

范围：2020年以来；数据截至2026-10-29。沿用前次GOOG、拆股调整且不含股息的收盘价。

## 计算口径

起算日为各年收盘价向下偏离SMA200最严重的日期。“新高”是之后首次收盘价严格超过起算日已知的历史最高日收盘价。前高从上市历史中寻找。2021年没有收盘价跌破SMA200，因此不纳入。

每年的最大偏离日期只能事后确定。该统计不是可实时执行的择时信号，也不能用来确定未来创新高的日期。

## 存档时当前状态

截至2026-10-29，GOOG收盘$282.32。历史最高收盘为$399.04（2026-05-13），需要上涨超过41.34%才能收盘创新高。

历史盘中最高为$404.47（2026-05-18），相对当前收盘需要上涨超过43.27%才能突破。这与收盘新高口径不同。
