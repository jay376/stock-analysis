# 指数比值分析：ChatGPT与Codex使用说明

快捷触发：直接发送 **A股估值水平**。默认分析创业板指／中证红利比值的历史相对高低位，输出年度2高2低、指数点位、最新值和图表。

本包包含可复用skill、计算脚本、示例日线、示例图表和可本地安装的技能插件。skill已在本次Codex环境创建；本包没有发布到公共插件目录。

## 最快使用：上传到ChatGPT

把完整ZIP上传到一个能运行Python和读取文件的ChatGPT对话，然后发送：

> 请解压这个文件包，读取index-ratio-trends/SKILL.md，运行附带分析脚本。先用包内截至2026-10-30的示例数据复现创业板指／中证红利分析。每年2个高点、2个低点，列出当天两个指数点位，并在回复中直接显示PNG趋势图和年度小图，提供HTML与CSV下载链接。明确注明数据截止日期，不把示例数据称作最新行情。

下一次分析可以上传新的成对日线CSV，或要求联网获取真实数据。ChatGPT的代码执行环境不一定能联网；无法获取时使用上传数据，不能虚构行情。

脚本只需要Python 3与matplotlib。普通本地环境可先安装matplotlib；ChatGPT代码环境通常已有。CSV列为date,numerator_close,denominator_close，日期YYYY-MM-DD；包内旧列名chinext_close、csi_dividend_close也支持。

解压后的示例命令：

```bash
python index-ratio-trends/scripts/analyze_ratio.py --input index-ratio-trends/assets/example_daily_2026-10-30.csv --end 2026-10-30 --out output --source "2026-10-30演示存档：东方财富，原研究经腾讯核对"
```

刷新行情（环境可联网时）：

```bash
python index-ratio-trends/scripts/analyze_ratio.py --fetch --start 2020-01-01 --out output
```

## 安装为原生skill／插件

官方文档说明：独立skill可在ChatGPT桌面版、Codex CLI和IDE中使用；通过插件分发的skill可用于ChatGPT的Chat与Work网页、桌面和手机入口。ChatGPT用@选择技能，Codex用$。

本包的plugins/index-ratio-trends/plugin.json是无MCP依赖的技能插件；.agents/plugins/marketplace.json提供本地marketplace入口。若已安装Codex CLI，可将解压目录加入本地marketplace：

```bash
codex plugin marketplace add "/你的路径/index-ratio-trends-package"
```

按官方流程在ChatGPT桌面版插件目录选择“指数比值分析”来源并安装，再在新的对话中用@选择“A股估值水平”。也可以在有权访问解压目录的ChatGPT Work／桌面Codex中调用内置@plugin-creator，要求它将本包现有插件加入个人marketplace。

网页／手机直接安装的分发入口依赖账户可用功能及插件分发方式；本ZIP不会自动成为公共目录插件。直接上传ZIP并运行脚本即可使用这套分析，不必等待发布。

Codex本地调用示例：

> 使用 $index-ratio-trends 分析创业板指与中证红利，自2020年以来每年2高2低，附当天两个指数点位、最新值与图表。

## 图形与输出

- ratio_trend.png：完整日线与年度高低点包络线，单列最新点。
- ratio_years.png：逐年小图，标注每个高低点的日期与比值。
- report.html：独立HTML，下载后浏览器打开；悬停点可查看当天两个指数点位、比值与状态，不需要CDN或网络。
- yearly_extremes.csv：所有年度所选点，包含两个指数点位及确认状态。
- daily_ratio.csv、analysis.json、report.md：完整数据与可复核报告。

ChatGPT应在回复中真正展示PNG，例如：

```markdown
![比值趋势图](sandbox:/mnt/data/output/ratio_trend.png)
[下载HTML](sandbox:/mnt/data/output/report.html)
```

具体路径以实际生成位置为准。HTML作为下载文件在浏览器查看，不承诺在聊天窗口内运行。

## 方法

以10%反向变化阶段转折点为候选，补入年度绝对最高与最低值；去重后每年选最高的2个高点、最低的2个低点，各类按日期排序。候选不足显示“—”。年度补点、样本边界、末端未确认点单独标注。高点①不必对应低点①；比值是价格指数相对表现，不含分红，也不是估值指标。
