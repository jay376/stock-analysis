## 独立检验计算方式

账户资产公式：每笔投入金额×估值日基金复权净值÷该笔买入日基金复权净值，再把全部已发生投入相加。独立审计没有导入回测程序，而是用原始NDX、IRX、QQQ、QLD数据和50位十进制算术重新构建价格路径，再用各笔投入直接估值每个交易日。
XIRR按实际入金日期计算，每年按365天折算。原程序用折现现金流二分求根；独立审计改为对数增长率下的终值方程，用带边界的牛顿法求解：期末资产=各笔投入×(1+年化收益率)^(该笔持有天数/365)之和。最终XIRR用最终日、峰值XIRR用峰值日，峰值后的投入不参与峰值XIRR。

| 检验 | 结果 |
|---|---|
| 原始数据独立重建 | 全部交易日通过；50位十进制计算 |
| 价格路径最大相对差异 | 7.661e-15 |
| 40组全部每日账户最大相对差异 | 4.885e-15 |
| 最终与峰值XIRR共80次独立求解 | 最大年化差异1.743e-12个百分点 |
| 18组全实盘账户直接按原始QLD复权价计算 | 最大相对差异9.992e-16 |
| 每年投入日期与本金 | 全部通过；每个年度10,000美元，只投入一次 |
| 最高资产日期、当日本金、最高累计收益率日期 | 全部通过 |

结论：在已说明的模型假设下，没有发现账户资产、最高值或XIRR的计算错误。误差仅为浮点运算精度范围。

模型边界：2006年以前不存在真实QLD，本表使用每日2倍模拟；QQQ成立前的NDX价格收益未补指数分配再投资，融资使用IRX代理并假设1%年费。这些会影响历史模拟结果，数值审计不能证明它们等于当时真实可实现业绩。1985首笔为1月31日；窗口为20个日历年度预算；2007以后起点尚未满20年。最高资产是事后每日收盘记录，没有在最高日卖出。
